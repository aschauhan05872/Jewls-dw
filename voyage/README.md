# Voyage Jewelry

Paris-inspired fine jewelry boutique — Express + SQLite3 storefront.

This is the **jewelry brand template**. The medical variant lives in `../medical-store/` (Med Doorshipp) and shares the same layout, CSS, checkout flow, and admin dashboard structure.

## Run

```bash
npm install
npm start
```

Open http://127.0.0.1:8080/

**Admin:** `/admin-login` — `admin` / `SecureTorPass123!`
