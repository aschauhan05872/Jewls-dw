# Run Jewls jewelry store on Windows

## One-time clone

Open **Command Prompt** or **PowerShell**:

```bat
mkdir "C:\Individual Projects" 2>nul
cd /d "C:\Individual Projects"
git clone https://github.com/aschauhan05872/Jewls-dw.git
cd Jewls-dw\jewelry-store
```

## Start the app

Double-click `start.bat`, or run:

```bat
npm install
npm start
```

Then open: http://127.0.0.1:8080

## Admin panel

- URL: http://127.0.0.1:8080/admin-login
- Username: `admin`
- Password: `SecureTorPass123!`

Requires [Node.js LTS](https://nodejs.org).
